# Душевно — сайт центра психологической помощи

Приложение на Vite + React + TypeScript: витрина услуг психолога с расценками
и личный кабинет с историей купленных услуг.

## Запуск

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production-сборка в dist/
    npm run preview    # локальный просмотр сборки
    npm run typecheck

## Личный кабинет

- Вход по имени, email и телефону; аккаунт создаётся автоматически.
- Данные хранятся в localStorage: профиль — ключ duchevno.user,
  покупки — duchevno.purchases. плюс email в нижнем регистре.
- Запись на услугу создаёт заказ со статусом «Ожидает оплаты», кнопка «Оплатить»
  переводит его в «Оплачено».
- Кабинет привязан к email: выход и вход с другим email показывают другую историю.

## Дизайн

Пастельная зелёная палитра, засечный шрифт в заголовках, полосатое меню с активным
тёмным пунктом, три карточки преимуществ поверх светлого фона с текстурой — по шаблону.
